# IREN (2026.11.12)

주가 차트를 보면 한숨부터 나옵니다. 52주 고점 \$70.71에서 지금은 \$20대 초반, 고점 대비 약 -70%입니다. 그런데 같은 회사의 계약 백로그는 \$203억으로 역대 최대입니다.

<b>IREN은 지금 무엇이 되어 가는 회사인가?</b>

비트코인 채굴사에서 AI 클라우드 회사로 갈아타는 중인 이 회사를, 나중에 다시 꺼내 볼 수 있도록 정리해 둡니다.

> 🎯 <b>핵심 한 줄:</b> IREN은 "완전 계약·완전 조달"된 >\$40억 ARR을 가진 GPU 소유형 네오클라우드입니다. 다만 시장은 계약의 가치보다 <b>인도 지연·자금조달·희석·텍사스 규제</b>를 먼저 가격에 반영하고 있고, <b>2027년 1\~2월 ARR 가동 여부</b>가 주가 방향을 가를 단일 최대 변수입니다.

<b>읽는 순서:</b> ① 어떤 회사인가 → ② 무엇으로 돈을 버나 → ③ 숫자로 보기 → ④ 누구와 계약했나 → ⑤ 2027년 계획 → ⑥ 주가와 밸류에이션 → ⑦ 강세 논리 → ⑧ 약세 논리 → ⑨ 체크포인트 → 나의 대응

## 🏭 ① IREN은 어떤 회사인가요?

2018년 호주 시드니에서 Daniel·Will Roberts 형제가 세운 <b>Iris Energy</b>가 출발점입니다. 캐나다 BC주의 값싼 수력 전기로 비트코인을 캐던 회사였죠.

쉽게 말하면, 이 회사의 진짜 자산은 채굴기가 아니라 <b>"전기와 땅"</b>이었습니다. 그렇게 모은 >5GW 전력과 >30,000에이커 부지 위에, 이제는 GPU를 깔아 AI 회사들에게 빌려주는 사업으로 갈아탔습니다. 비트코인 채굴은 <b>2026-12-31까지 사실상 종료</b>합니다.

## 🗺️ ⑤ 2027년, 무엇을 하려고 하나요?

| 시점 | 목표 |
| --- | --- |
| 2027-01-31(최대 2월 말) | 0.3GW IT 가동 → <b>>\$40억 ARR</b> |
| 2027년 봄 | ERCOT Batch Zero 최종 MW 배분(Sweetwater) |
| 2027년 4분기 | Sweetwater 1 수냉 300MW gross 인도 |
| 2027년 말 | 누적 0.8GW IT |
| 2028\~ | Kiowa(오클라호마 1.6GW), Badajoz(스페인 300MW) |

원래 2026년 말 목표였던 ARR 가동이 늦어진 이유는 마이크로소프트가 200MW 전체를 최신 프런티어 모델용으로 쓰려고 요청한 <b>네트워크 설계 변경</b>과 공급사 일정입니다. 회사는 이 지연에 재무적 페널티가 없다고 밝혔습니다.

> 💡 <b>돈은 어디서?</b> FY27 잔여 capex 약 \$150억 중 \$90억은 확보(현금·약정 금융·선지급), <b>\$60억은 아직 조달 필요</b>입니다. 이 \$60억이 GPU 금융으로 채워지면 긍정적이지만, ATM 주식 발행으로 채워지면 희석입니다. 발행주식은 이미 9개월 새 약 28% 늘었습니다(3.32억 → 4.24억 주).

> 🤔 0.8GW IT × MW당 \$2,000만\~\$2,200만으로 단순 환산하면 연 \$160억\~\$176억 ARR 잠재력입니다. 제 산술일 뿐 회사 가이던스가 아닙니다.
